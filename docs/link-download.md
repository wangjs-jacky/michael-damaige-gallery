# 链接下载与逐期更新

用户将 B 站视频域名换成 `damaige.paws.rodeo`，保留 `/video/BV…/`，即可自动获取这一期的图集。`/download/` 支持粘贴完整链接、分享文案、b23.tv 短链或 BV 号，也提供返回图集阅读的入口。

图片包在请求时由这一期原图组成，服务器不提前生成新 ZIP。图片生成或导入时计算 CRC、SHA 和大小；`POST /api/resolve` 返回这期的下载计划和原图校验信息，`raw=1` 直接输出 ZIP 流。HEAD 只返回元数据，不打开图片。Worker 用背压与取消传递控制原图读取，使用 FixedLengthStream 输出精确长度。

下载页在内存保护范围内校验 ZIP 目录结构、成员名称、大小和每张原图 SHA 后保存，超过阈值交由浏览器直接下载。输入变化或重新提交会取消旧操作，单次下载有期限，没有任务状态轮询。短链解析只允许固定 B 站主机和有限跳转，不将外部地址交给通用代理。

新增内容由 [逐期流水线](episode-pipeline.md) 处理：发现新投稿、核对作者、采集原片、本地转写、选择原字幕与画面、视觉复核、生成长图，最后逐期追加目录和发布日期。新内容标为 `review`，原始转写、人名书名准确性和跨卡上下文仍需核对。当前为单次 CLI 触发，尚未安装定时后台服务，也未连接公网网页生成任务后端。

发布从当前正式快照增量生成独立冻结目录。旧图片、旧内容认可状态、页面样式、响应头和部署配置保持；只允许目录、日期、主页内联数据、下载页和新一期图片变化。公开清单与变更证明绑定哈希，私有素材不进入公开资源。不能用 GitHub 较旧的首页覆盖正式照片墙。旧 ZIP 保留作历史回退，当前下载计划不依赖它们。

首个真实新增样本已完成原片到 17 张长图、正式作品墙阅读、改域名自动保存 19.6MB ZIP；独立解包确认全部 CRC 与原图 SHA 一致。Node 回归、真实 workerd、HTTP 分发和执行机浏览器证据分别记录。执行机为 Mac mini；用户实体手机尚未直接验收。部署快照及运行证据保存在私有部署工作区，公开源码不含凭据或本机运行资料。
