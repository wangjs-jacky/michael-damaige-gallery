# B站链接转发与粘贴下载

用户已在会话中选择“实现链接转发和粘贴下载”。目标是在看完大麦哥视频后，直接取得已有的整期图片集。

- 将 B 站域名替换为 `damaige.paws.rodeo`，保留 `/video/BV…/`，匹配成功后自动准备、校验并保存现有图集包，无需再点下载。下载页显示实际进度和失败提示；`raw=1` 提供原生附件跳转供脚本使用。
- `/download/` 提供粘贴完整网址、B站分享文案、b23.tv短链或BV号的表单。解析后显示作品标题、图数、包大小，用户点“下载整期图片”开始下载，并可回到图集阅读。
- 错误、未收录、短链不可用、网络失败分别给出可恢复提示；不制作新视频，不保存用户分享内容。
- 复用正式照片墙的深浅主题和已有资源，只添加入口，不用GitHub旧首页替换正式稿。

方案比较：纯静态跳转足以支持已知BV，但不能解析b23短链；新增完整后端/数据库没有必要。采用现有Worker追加轻量请求处理和ASSETS绑定。短链只向精确白名单主机发出有限协议跳转，统一超时，不读取B站正文，不轮询状态。

实现顺序：

1. 独立worktree编写解析与请求处理；用Node测试覆盖真实输入和禁止的网络目标。
2. 添加可键盘操作的下载页和主题；用当前正式快照生成新快照并保留所有旧资源。
3. 在workerd验证ASSETS与路由；独立代码审查；发布前冻结旧首页与Worker配置，保留完整回退。
4. 正式入口验证粘贴、直达、错误、真实ZIP落盘和窄屏；记录当前宿主与设备边界。

验收：已收录BV匹配正确包；恶意URL不触发外域访问；b23单次解析可结束；新旧图库与资源均可用；ZIP完整字节和下载头正确。上线回执、活动版本读取和用户实体手机验收分别报告。

下载页只在用户提交或进入明确的自动下载链接时请求一次。包的读取限制为目录声明大小且不超过25MiB，核对完整字节和SHA256后请求保存；总超时180秒。输入变化或重提会取消旧请求，旧包不能晚到后误保存；没有校验能力或跨域旧OSS地址时保留原生下载并如实提示。

验证：Node解析/路由、下载状态与发布保护回归，以及Ego真实Worker路径分开验证。当前生产快照、分发回执、全量字节及当前设备边界由部署档案维护；公开源码不包含认证、运行截图或本机发行目录。
